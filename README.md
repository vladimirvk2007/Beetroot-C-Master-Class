# Beetroot EMB — Навчальний проєкт електронного годинника

Навчальний об'єктно-орієнтований C++ проєкт годинника для мікроконтролера STM32 (BlackPill STM32F411CE).

Проєкт демонструє побудову вбудованої системи за принципами ООП, використання абстрактних інтерфейсів, композиції та поліморфізму для роботи з різними типами індикаторів (4-розрядний 7-сегментний LED-дисплей, I2C OLED SSD1306) і джерелами тактових імпульсів.

---

## 🛠 Апаратна та програмна платформа

- **MCU:** STM32F411CEU6 (ARM Cortex-M4, 100 МГц)
- **Плата:** WeAct Studio BlackPill V2.0
- **Фреймворк:** STM32Cube HAL
- **Середовище збірки:** PlatformIO
- **Мова:** C++ / C

---

## 🧱 Архітектура проєкту та об'єктна модель

Проєкт розділено на модулі та окремі абстракції з чіткими зонами відповідальності:

### 1. Ядро годинника (`Inc/clock/`, `Src/clock/`)
- **`Clock`** — основний клас годинника. Керує відліком часу (години, хвилини, секунди), логікою перемикання двокрапки та оновленням відображення. Працює виключно через абстрактні інтерфейси:
  - **`ClockTicker`** (`Inc/clock/clock_ticker.h`) — абстрактний інтерфейс джерела секундних імпульсів (`initialize()`, `consumeSecondTick()`).
  - **`ClockDisplay`** (`Inc/clock/clock_display.h` / `Inc/indicator/clock_display.h`) — абстрактний інтерфейс годинникового індикатора (`initialize()`, `setTime()`, `setColon()`, `refresh()`, `blank()`).
- **`RealClockTicker`** (`Inc/clock/real_clock_ticker.h`, `Src/clock/real_clock_ticker.cpp`) — реалізація `ClockTicker` на базі системного таймера `HAL_GetTick()`.

### 2. Модуль індикації (`Inc/indicator/`, `Src/indicator/`)
- **`Seg7`** — клас керування одним 7-сегментним індикатором. Підтримує виведення цифр і символів, керування десятковою крапкою та програмний поворот на 180° (`rotated180`).
- **`Seg7Display`** — клас динамічного мультиплексування 4-розрядного 7-сегментного дисплея.
- **`Seg7ClockDisplay`** — реалізація інтерфейсу `ClockDisplay` для 4-розрядного 7-сегментного індикатора.
- **`OledClockDisplay`** — реалізація інтерфейсу `ClockDisplay` для OLED-дисплея (SSD1306, 128x64) по шині I2C.

### 3. Драйвери периферії (`Inc/i2c/`, `Src/i2c/`, `Inc/oled/`, `Src/oled/`)
- **`i2c`** — апаратний драйвер I2C1 (PB6 — SCL, PB7 — SDA).
- **`oled`** — драйвер графічного контролера SSD1306 (підтримка геометрії, шрифтів BDF та Latin 8x8).

### 4. Точка входу прикладної логіки (`Src/app/main_app.cpp`)
- `main_cpp()` об'єднує компоненти (Ticker, Display, Clock), ініціалізує час і запускає головний цикл оновлення годинника `clock.update()`.

## 🔌 Підключення компонентів

### 4-розрядний 7-сегментний індикатор:
- **Сегменти (GPIOA):**
  - A — PA5, B — PA4, C — PA3, D — PA2, E — PA1, F — PA0, G — PA6, DP — PA7
- **Вибір розрядів (Anodes / Cathodes):**
  - Розряд 1 — PA8
  - Розряд 2 — PA9
  - Розряд 3 — PA10 (програмно розгорнутий на 180° для формування двокрапки)
  - Розряд 4 — PB3

### I2C OLED дисплей (SSD1306 128x64):
- SCL — PB6
- SDA — PB7
- Живлення — 3.3V / GND

## 🚀 Збірка та завантаження

Проєкт збирається за допомогою PlatformIO:

```bash
# Збірка прошивки
pio run

# Прошивка через ST-Link
pio run -t upload
```
