# Питання 11. Побітові операції (Bitwise Operations)

## 1. Що таке побітові операції

Побітові операції працюють з бітами числа напряму (0/1), а не з числом як математичним значенням.

Це особливо важливо в embedded, бо регістри периферії, прапорці стану і протоколи часто кодуються на рівні бітів.

---

## 2. Де це використовується в embedded

1. Робота з регістрами MCU
- увімкнути/вимкнути конкретний біт;
- перевірити прапорець готовності;
- налаштувати поле режиму.

2. Протоколи і пакети
- упаковка кількох дрібних полів в один байт/слово;
- парсинг кадрів по бітових масках.

3. Оптимізація пам'яті
- компактне зберігання набору boolean-прапорців.

---

## 3. Основні оператори

Для `a` і `b`:

1. `&` (AND)
- Біт = 1 лише якщо обидва біти 1.

2. `|` (OR)
- Біт = 1 якщо хоча б один біт 1.

3. `^` (XOR)
- Біт = 1 якщо біти різні.

4. `~` (NOT)
- Інвертує всі біти.

5. `<<` (left shift)
- Зсув бітів вліво на N позицій.

6. `>>` (right shift)
- Зсув бітів вправо на N позицій.

---

## 4. Базові патерни

### 1. Встановити біт

```c
reg |= (1u << n);
```

### 2. Скинути біт

```c
reg &= ~(1u << n);
```

### 3. Перемкнути біт (toggle)

```c
reg ^= (1u << n);
```

### 4. Перевірити біт

```c
if (reg & (1u << n)) {
    // біт встановлений
}
```

### 5. Оновити біт за умовою

```c
if (value) {
    reg |= (1u << n);
} else {
    reg &= ~(1u << n);
}
```

---

## 5. Маски і поля бітів

Приклад: у 8-бітному регістрі:

- біти [0..1] = mode
- біт [2] = enable
- біти [3..7] = reserved

### Маски

```c
#define MODE_MASK   0x03u      // 00000011
#define EN_MASK     0x04u      // 00000100
```

### Прочитати поле mode

```c
uint8_t mode = reg & MODE_MASK;
```

### Записати поле mode

```c
reg = (uint8_t)((reg & ~MODE_MASK) | (new_mode & MODE_MASK));
```

### Встановити enable

```c
reg |= EN_MASK;
```

---

## 6. Зсуви і складання значень

### Зібрати 16-бітне значення з двох байтів

```c
uint16_t value = (uint16_t)((high << 8) | low);
```

### Розбити 16-бітне значення на байти

```c
uint8_t high = (uint8_t)(value >> 8);
uint8_t low  = (uint8_t)(value & 0xFFu);
```

---

## 7. Відмінності C і C++ тут

Побітові оператори однакові в C і C++.

Практичні відмінності більше в стилі:

1. У C++ частіше використовують `constexpr` для масок.
2. У C++ з `enum class` інколи пишуть helper-функції для `|`/`&`.
3. У C++ простіше робити типобезпечні обгортки над регістрами.

---

## 8. Типові помилки

1. Забули дужки у виразах

Неправильно:

```c
if (reg & 1u << n) { }
```

Краще:

```c
if (reg & (1u << n)) { }
```

2. Використання signed-типів у бітовій арифметиці
- Може дати неочікувані результати на зсувах.
- Краще використовувати `uint8_t/uint16_t/uint32_t`.

3. Зсув на занадто велику кількість біт
- `1u << 32` для 32-бітного типу це UB.

4. Неправильна маска при оновленні полів
- Забувають очистити поле перед OR.

5. Ігнорування endianness при розборі багатобайтних значень.

## 9. Корисні макроси/хелпери

### C-стиль

```c
#define BIT(n)              (1u << (n))
#define SET_BIT(x, n)       ((x) |= BIT(n))
#define CLEAR_BIT(x, n)     ((x) &= ~BIT(n))
#define TOGGLE_BIT(x, n)    ((x) ^= BIT(n))
#define TEST_BIT(x, n)      (((x) & BIT(n)) != 0u)
```

### C++ constexpr-стиль

```cpp
#include <cstdint>

constexpr uint32_t bit(unsigned n) {
    return 1u << n;
}
```

### Повний приклад з constexpr

```cpp
#include <cstdint>

constexpr uint32_t bit(unsigned n) {
    return 1u << n;
}

constexpr uint32_t MODE_MASK = bit(0) | bit(1);
constexpr uint32_t EN_MASK   = bit(2);

constexpr bool is_enabled(uint32_t reg) {
    return (reg & EN_MASK) != 0u;
}

constexpr uint32_t set_mode(uint32_t reg, uint32_t mode) {
    return (reg & ~MODE_MASK) | (mode & MODE_MASK);
}

uint32_t reg = 0u;
reg = set_mode(reg, 2u);
reg |= EN_MASK;

// Очікувано: mode = 2, enable = 1
static_assert((set_mode(0u, 2u) & MODE_MASK) == 2u, "Mode encode error");
static_assert(is_enabled(EN_MASK), "Enable bit check error");
```

## 10. Приклад для заняття

```cpp
#include <cstdint>
#include <iostream>

int main() {
    uint8_t reg = 0x00u;

    // set bit 2
    reg |= (1u << 2);

    // set bit 0
    reg |= (1u << 0);

    // clear bit 2
    reg &= ~(1u << 2);

    // toggle bit 1
    reg ^= (1u << 1);

    std::cout << "reg = 0x" << std::hex << static_cast<int>(reg) << "\n";

    if (reg & (1u << 0)) {
        std::cout << "bit0 is set\n";
    }

    return 0;
}
```

---

## 11. Практичні рекомендації

1. Для бітової логіки використовуйте unsigned fixed-width типи.
2. Завжди ставте дужки у виразах зі зсувами і масками.
3. Виносьте маски у `#define` або `constexpr` з промовистими іменами.
4. Для полів спершу очищайте бітову область, потім записуйте нове значення.
5. Перевіряйте, що кількість біт зсуву не виходить за межі типу.

---

## 12. Висновок

Побітові операції це базовий інструмент embedded-розробки. Якщо добре володіти масками, зсувами і патернами set/clear/test, робота з регістрами і протоколами стає значно простішою та надійнішою.
