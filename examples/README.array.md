# ETL Array API

Цей файл описує базовий API контейнера `etl::array`.

Пов'язаний приклад: `etl_array_example.cpp`.

## Коротко

- Фіксований розмір на етапі компіляції.
- Дані зберігаються всередині контейнера.
- Немає операцій зміни розміру (`push_back`, `insert`, `erase`).

## Основний API

### Доступ до елементів

- `operator[](index)`
- `at(index)`
- `front()`
- `back()`
- `data()`

### Ітератори

- `begin()`, `end()`
- `cbegin()`, `cend()`
- `rbegin()`, `rend()`
- `crbegin()`, `crend()`

### Ємність

- `size()`
- `max_size()`
- `empty()`

### Операції

- `fill(value)`
- `swap(other)`

## Нотатки

- Елементи можна змінювати, якщо контейнер не `const`.
- Розмір змінювати не можна.
