# Ring Buffer (C++)

Цей приклад показує шаблонний кільцевий буфер на C++.

## Файли

- main.cpp — тестова програма
- ring_buffer.h — шаблон класу RingBuffer

## Збірка

```bash
cd examples/Ring_buffer_C++
make
```

## Запуск

```bash
./ring_cpp.exe
```

## Що демонструє

- шаблон класу з фіксованою місткістю
- push/pop
- перевірку full/empty
