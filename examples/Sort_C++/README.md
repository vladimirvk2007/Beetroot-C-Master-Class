# Sort (C++)

Цей приклад показує шаблонну реалізацію Bubble Sort на C++.

## Файли

- main.cpp — тестова програма
- sort.h — шаблонна функція bubble_sort

## Збірка

```bash
cd examples/Sort_C++
make
```

## Запуск

```bash
./sort_cpp.exe
```

## Що демонструє

- шаблонну функцію сортування
- роботу з масивом фіксованого розміру
- використання std::swap
