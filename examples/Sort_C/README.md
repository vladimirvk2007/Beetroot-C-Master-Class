# Sort (C)

Цей приклад показує бульбашкове сортування (Bubble Sort) на C.

## Файли

- main.cpp — тестова програма
- sort.h — оголошення функції
- sort.c — реалізація bubble_sort

## Збірка

```bash
cd examples/Sort_C
make
```

## Запуск

```bash
./sort_c.exe
```

## Що демонструє

- сортування масиву цілих чисел
- оптимізацію через прапорець swapped
